# Troubleshooting (Sorun Giderme)

| Symptom                                                | Cause / fix                                                                                                                                                                                            |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `EACCES: permission denied, link … quantforge.lock`    | Android forbids hard links in app storage. Fixed in this release (the lock falls back to an exclusive create). Update with `./update.sh QUANTFORGE_AI_PRO_TERMUX.zip`.                                 |
| `node:sqlite is unavailable`                           | Node.js older than 22.13. Termux: `pkg install nodejs-lts` (or `pkg install nodejs`). Check with `node -e "require('node:sqlite')"`.                                                                   |
| `npm ci` fails on Termux                               | Use `./install.sh`: it installs with `--omit=dev --ignore-scripts`, so dev tools without Android binaries (TypeScript 7, bun, biome) are never needed. Make sure the release `dist/` folder exists.    |
| Need to rebuild on the phone                           | `npm ci --ignore-scripts && npm run build:portable` (pure-JS TypeScript 5.9).                                                                                                                          |
| `authentication failed (**apikey** …)`                 | Twelve Data key missing or wrong: `TWELVEDATA_API_KEY` in the environment or `~/.quantforge/credentials.env` (chmod 600). Run `quantforge doctor`.                                                     |
| `UnsafeFileError … readable by others`                 | `chmod 600 ~/.quantforge/credentials.env ~/.quantforge/dashboard-token && chmod 700 ~/.quantforge`                                                                                                     |
| `daily API budget exhausted`                           | The plan's 800 credits/day are nearly used (other apps using the same key count too). It resets at 00:00 UTC. Lower `data.backfillDays` or raise `data.apiBudget` if your plan allows.                 |
| `This symbol is available starting with the Grow plan` | Expected for XAG/USD on the basic plan. It is skipped automatically.                                                                                                                                   |
| Dashboard does not open                                | Check `./status.sh`. Use `http://127.0.0.1:<port>/` on the **same phone**. Check `~/.quantforge/logs/daemon.out`. Is the port taken? Change `dashboard.port`.                                          |
| "login required" loops                                 | Token mismatch: `cat ~/.quantforge/dashboard-token`. Cookies must be allowed for 127.0.0.1.                                                                                                            |
| `QuantForge is already running`                        | `./status.sh`. If no process exists, `./start.sh` clears a stale PID and lock automatically. A lock that still persists is reported with the file to delete.                                           |
| Stops for hours / gaps in data                         | Android killed Termux. Set Battery → Unrestricted, use the wake lock, and use Termux:Boot or `healthcheck.sh --restart` from a loop. On restart, missed bars are fetched and missed stops are applied. |
| `degraded: market open but data is N bars old`         | Provider outage or no network. See Data Providers. The router retries and fails over; trading is blocked while data is stale.                                                                          |
| All decisions are NO_TRADE                             | Expected when no strategy is validated (see Strategy Discovery). Other reasons are listed per decision: vetoes, risk rules, confidence.                                                                |
| `risk budget … is below the loss of the minimum lot`   | The stop is too wide for 1% of the balance at 0.01 lot. The trade is refused by design.                                                                                                                |
| Discovery says it needs 3000 clean bars                | Run `quantforge backfill` (or wait for the start-up backfill), then run discovery again.                                                                                                               |
| Ledger mismatch / kill switch at start                 | Database edited or corrupted. Restore the latest backup with `./stop.sh && ./restore.sh <file>`.                                                                                                       |
| `database integrity check` failure                     | Restore from a backup. The pre-restore copy is kept.                                                                                                                                                   |

Logs: `~/.quantforge/logs/quantforge.log` (JSON lines; secrets redacted), the System Logs page, and
`node dist/quantforge/cli/main.js status`.
